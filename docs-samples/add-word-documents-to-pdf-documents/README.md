# Add Word Documents to PDF Documents

A Word document can be rendered in the pages of a PDF document created with the T:EvoPdf.Next.PdfDocument class, between the text, images and other elements added from code. The content starts at a position in the current page and flows to as many new pages as it needs, laid out inside the margins of the PDF document. The document keeps its structure, headings, links and images.

Source topic: https://www.evopdf.com/help/evopdf-next-dotnet/html/add-word-documents-to-pdf-documents.htm
