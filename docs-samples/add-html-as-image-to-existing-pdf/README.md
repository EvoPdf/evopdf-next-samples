# Add HTML as Image to Existing PDF

The T:EvoPdf.Next.PdfEditor class renders an HTML document as an image in a page of a loaded document with M:EvoPdf.Next.PdfEditor.AddHtmlImage(System.Int32,EvoPdf.Next.PdfHtmlImageElement), which takes the number of the page to draw in and a T:EvoPdf.Next.PdfHtmlImageElement, the element described in the topic. In an edited document the position of the element is given from the top left corner of the page and the image is scaled down to the right edge of the page when it is wider.

Source topic: https://www.evopdf.com/help/evopdf-next-dotnet/html/add-html-as-image-to-existing-pdf.htm
