# Add Excel Workbooks to PDF Documents

An Excel workbook can be rendered in the pages of a PDF document created with the T:EvoPdf.Next.PdfDocument class, between the text, images and other elements added from code. The worksheets start at a position in the current page and flow to as many new pages as they need, laid out inside the margins of the PDF document. The worksheets keep the formatting, the images and the shapes of the workbook.
