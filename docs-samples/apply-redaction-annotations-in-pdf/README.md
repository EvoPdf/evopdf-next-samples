# Apply Redaction Annotations in PDF

Redaction annotations mark the areas of a PDF document that must be redacted, during a review in a PDF viewer or with M:EvoPdf.Next.PdfRedactor.SaveRedactionMarks, without removing the content yet. The T:EvoPdf.Next.PdfRedactor class applies these annotations: the content of each marked area is permanently removed, the area is covered with the fill color and the overlay text of the annotation and the annotations are removed from the saved document.

Source topic: https://www.evopdf.com/help/evopdf-next-dotnet/html/apply-redaction-annotations-in-pdf.htm
