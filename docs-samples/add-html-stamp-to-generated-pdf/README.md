# Add HTML Stamp with Page Numbering to Generated PDF

EVO HTML to PDF Converter allows you to add stamps to the generated PDF document using any valid HTML markup and elements. The HTML content can also include the template variables {page_number} and {total_pages} to insert page numbering.
