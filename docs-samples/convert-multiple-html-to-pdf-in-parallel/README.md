# Convert Multiple HTML Pages to PDF in Parallel

EvoPdf Next can convert multiple HTML documents to PDF in parallel tasks using the asynchronous HTML to PDF methods such as M:EvoPdf.Next.HtmlToPdfConverter.ConvertUrlAsync(System.String,System.Threading.CancellationToken) and merge the resulted PDFs using the M:EvoPdf.Next.PdfMerge.AddPdf(System.Byte[],System.String) method of T:EvoPdf.Next.PdfMerge class. The PdfMerge class allows you to set security options, configure PDF viewer preferences and apply a digital signature to the resulting PDF.
