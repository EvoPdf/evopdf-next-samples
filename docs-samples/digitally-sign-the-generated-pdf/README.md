# Add a Digital Signature to Generated PDF Document 

EVO HTML to PDF Converter allows you to add digital signatures to the generated PDF document. In order to add digital signatures you need a certificate with private and public keys. These certificates are usually stored in a .pfx or a .p12 file in PKCS#12 format and they can be password protected. A digital signature is represented by a T:EvoPdf.Next.PdfDigitalSignature object. An object of this type is exposed by the P:EvoPdf.Next.HtmlToPdfConverter.DigitalSignature property of the HTML to PDF Converter class.

Source topic: https://www.evopdf.com/help/evopdf-next-dotnet/html/digitally-sign-the-generated-pdf.htm
