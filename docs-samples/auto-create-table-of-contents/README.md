# Auto Create Table of Contents

EVO HTML to PDF Converter can be configured to automatically create a table of contents in a PDF document based on H1 to H6 heading tags found in HTML document by simply turning on the P:EvoPdf.Next.PdfDocumentOptions.GenerateTableOfContents option. An object of the T:EvoPdf.Next.PdfDocumentOptions type is exposed by the P:EvoPdf.Next.HtmlToPdfConverter.PdfDocumentOptions property. The code below can be used to enable the table of contents generation in the PDF document.
