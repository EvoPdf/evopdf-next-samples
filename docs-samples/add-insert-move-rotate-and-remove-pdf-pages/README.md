# Add, Insert, Move, Rotate and Remove PDF Pages

The T:EvoPdf.Next.PdfEditor class can change the pages of an existing PDF document: it adds blank pages at the end, inserts blank pages at a position, moves pages to another position, rotates pages and removes pages. The content, the links and the bookmarks of the existing pages are not changed by these operations.
