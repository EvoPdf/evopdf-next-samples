# Create PDF Documents with Gradient Fills

The shapes of a PDF document can be painted with a linear gradient instead of a solid color. A T:EvoPdf.Next.PdfGradientFill object changes smoothly from a start color to an end color across the bounds of the shape, along one of the directions of the T:EvoPdf.Next.PdfGradientDirection enumeration.
