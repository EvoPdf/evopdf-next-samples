# Add Bookmarks and Open Action to Generated PDF

The bookmarks of the PDF document generated by the HTML to PDF converter can be created automatically from the headings of the HTML document, as described in the topic and they can be added from code to the P:EvoPdf.Next.PdfDocumentOptions.Bookmarks collection, after the bookmarks created from the headings. A bookmark goes to a page at a given location and zoom or opens a web address, it can have child bookmarks and a bold, italic or colored title.

Source topic: https://www.evopdf.com/help/evopdf-next-dotnet/html/add-bookmarks-and-open-action.htm
