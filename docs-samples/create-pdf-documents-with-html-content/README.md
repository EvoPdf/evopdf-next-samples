# Create PDF Documents with HTML Content

The T:EvoPdf.Next.PdfHtmlElement class renders HTML content in the pages of a document being created with T:EvoPdf.Next.PdfDocument. The content starts at a position in the current page, after the elements added before it and flows to as many new pages as it needs, laid out inside the margins of the document. The elements added after it go to its last page, below the rendered content. The HTML is given as a string with a base URL or as the URL of a page, like for the HTML to PDF converter.
