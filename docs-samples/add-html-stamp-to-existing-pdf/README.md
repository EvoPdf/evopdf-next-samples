# Add HTML Stamp with Page Numbering to Existing PDF

The EvoPdf Next library allows you to add stamps to an existing PDF document using any valid HTML markup and elements. The HTML content can also include the template variables {page_number} and {total_pages} to insert page numbering.

Source topic: https://www.evopdf.com/help/evopdf-next-dotnet/html/add-html-stamp-to-existing-pdf.htm
