# Split PDF Documents

The T:EvoPdf.Next.PdfSplit class extracts pages from an existing PDF document, removes pages from it and splits it in several documents, by a number of pages or by page ranges. The extracted pages keep their content, links, bookmarks, form fields and annotations. The document is loaded from a file or from memory, with the password of a protected document and P:EvoPdf.Next.PdfSplit.PageCount gives its number of pages.
