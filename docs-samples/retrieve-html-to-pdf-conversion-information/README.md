# Retrieve HTML to PDF Conversion Information

After a conversion completes, the P:EvoPdf.Next.HtmlToPdfConverter.ConversionInfo property of T:EvoPdf.Next.HtmlToPdfConverter holds a T:EvoPdf.Next.HtmlToPdfConversionInfo object with the number of pages generated from the HTML content, the pages of the table of contents and of the external PDF documents inserted before and after it, the total number of pages of the generated document and the zoom at which the HTML content was drawn.
