# Convert Word to PDF with Outline, Open Action and Attachments

The Word to PDF Converter can create the outline of the generated PDF document from the headings of the Word document, add your own bookmarks to it, set the action executed when the document is opened and attach files to the document. The options are exposed by the T:EvoPdf.Next.WordToPdfDocumentOptions object of the P:EvoPdf.Next.WordToPdfConverter.PdfDocumentOptions property. The bookmarks, open action and attachment options are also available in the Excel, RTF and Markdown to PDF converters and the outline created from the headings in the RTF and Markdown to PDF converters.
