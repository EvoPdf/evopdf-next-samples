# Convert Word to PDF with Document Headers and Footers

The Word to PDF Converter renders the running header and footer of the Word document on the PDF pages, with the page number and page count fields they contain and with a different first page when the document has one. The feature is controlled by the P:EvoPdf.Next.WordToPdfDocumentOptions.UseHeaderFooterFromWord property, which is true by default.

Source topic: https://www.evopdf.com/help/evopdf-next-dotnet/html/convert-word-to-pdf-with-document-headers-and-footers.htm
