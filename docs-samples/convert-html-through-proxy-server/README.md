# Convert HTML through a Proxy Server

EVO HTML to PDF Converter can load the HTML page and its resources through a HTTP or a SOCKS5 proxy server. The proxy is configured with the T:EvoPdf.Next.ProxyOptions object exposed by the P:EvoPdf.Next.HtmlToPdfConverter.ProxyOptions property. By default no proxy is set and the network settings of the system are used.

Source topic: https://www.evopdf.com/help/evopdf-next-dotnet/html/convert-html-through-proxy-server.htm
