# Convert RTF to PDF with Document Headers and Footers

The RTF to PDF Converter renders the running header and footer of the RTF document on the PDF pages, with the page number and page count fields they contain and with a different first page when the document has one. The feature is controlled by the P:EvoPdf.Next.RtfToPdfDocumentOptions.UseHeaderFooterFromRtf property, which is true by default.

Source topic: https://www.evopdf.com/help/evopdf-next-dotnet/html/convert-rtf-to-pdf-with-document-headers-and-footers.htm
