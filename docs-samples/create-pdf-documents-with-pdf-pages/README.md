# Create PDF Documents with Pages of Other PDF Documents

The T:EvoPdf.Next.PdfPageElement class draws a page of an existing PDF document in a page of the document being created, at a given position and size, optionally rotated and with a given opacity. The drawn page keeps its content, its fonts, images and vector graphics, its links and form fields when the annotations are included and its structure when both documents are tagged. The element is added with M:EvoPdf.Next.PdfDocument.AddPdfPage(EvoPdf.Next.PdfPageElement), which returns the rectangle used by the drawn page.
