# Fill, Flatten and Edit PDF Forms

The P:EvoPdf.Next.PdfEditor.Form property of T:EvoPdf.Next.PdfEditor gives the interactive form of a loaded document as a T:EvoPdf.Next.PdfForm object. The form reads the fields of the document, fills them with values, imports the values of a FDF or XFDF file, changes the appearance of the fields, makes them read-only or hidden, renames and removes them and flattens them to static content. The current values can be exported as FDF. The changes are written when the document is saved with M:EvoPdf.Next.PdfEditor.Save. P:EvoPdf.Next.PdfEditor.ContainsForm tells if the loaded document has a form.
