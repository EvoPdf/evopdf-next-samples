# Create PDF Forms from HTML Forms

EVO HTML to PDF Converter can be configured to automatically convert HTML form controls to interactive PDF form fields by setting the P:EvoPdf.Next.PdfDocumentOptions.GeneratePdfFormFields property to true. An object of type T:EvoPdf.Next.PdfDocumentOptions is exposed by the P:EvoPdf.Next.HtmlToPdfConverter.PdfDocumentOptions property
