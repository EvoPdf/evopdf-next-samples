# Create PDF Forms from Code

The fields of an interactive PDF form can be created from code in a document being created with T:EvoPdf.Next.PdfDocument or added to an existing document loaded in T:EvoPdf.Next.PdfEditor, with the M:EvoPdf.Next.PdfDocument.AddFormField(EvoPdf.Next.PdfFormField) and M:EvoPdf.Next.PdfEditor.AddFormField(EvoPdf.Next.PdfFormField) methods. The fields have a name, a position, a size and an appearance, they can be required or read-only and they can carry scripts and actions executed by the PDF viewer. The fields of a HTML form are converted automatically by the HTML to PDF converter, as described in the topic; this topic describes the fields created from code.
