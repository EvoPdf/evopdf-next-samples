# Add Pages of Other PDF Documents to Existing PDF

The T:EvoPdf.Next.PdfEditor class draws a page of another PDF document in the pages of a loaded document with M:EvoPdf.Next.PdfEditor.AddPdfPage(System.Int32,EvoPdf.Next.PdfPageElement), which takes the number of the page to draw in and a T:EvoPdf.Next.PdfPageElement, the element described in the topic. The drawn page keeps its size or is scaled to fit the given width and height, it can be rotated around a pivot point and it can have an opacity. The links and form fields of the drawn page are added to the edited page when the annotations are included.

Source topic: https://www.evopdf.com/help/evopdf-next-dotnet/html/add-pdf-pages-to-existing-pdf.htm
