# Redact Areas and Pages of PDF

The T:EvoPdf.Next.PdfRedactor class permanently removes the content of some areas and pages of an existing PDF document. The text, images and graphics inside an area are removed, the content partially inside an area is cut at the area boundary, so the text characters and the image pixels outside the area are kept. The area is then covered with a fill color, an image and an overlay text.

Source topic: https://www.evopdf.com/help/evopdf-next-dotnet/html/redact-areas-and-pages-in-pdf.htm
