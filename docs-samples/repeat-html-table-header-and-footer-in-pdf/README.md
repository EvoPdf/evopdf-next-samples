# Repeat HTML Table Header and Footer in PDF Pages

The EvoPdf Next HTML to PDF Converter provides the P:EvoPdf.Next.PdfDocumentOptions.RepeatTableHeaderFooter property, which enables the automatic repetition of HTML table header (thead) and footer (tfoot) sections on each page when converting HTML to PDF. This is particularly useful for long tables that span multiple pages, ensuring that headers and footers remain visible throughout the document. The default value is false. An object of type T:EvoPdf.Next.PdfDocumentOptions is accessible through the P:EvoPdf.Next.HtmlToPdfConverter.PdfDocumentOptions property.
