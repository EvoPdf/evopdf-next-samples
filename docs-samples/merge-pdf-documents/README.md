# Merge PDF Documents

The T:EvoPdf.Next.PdfMerge class merges PDF documents, or selected pages of them, blank pages and images into a single PDF document. The form fields, bookmarks, annotations, internal links and scripts of the merged documents are kept. The merged documents can be password protected, the merged document can have its own document information, security options, viewer preferences, bookmarks, open action and digital signature and HTML templates can be drawn in all its pages, for example a footer with the page numbers.
