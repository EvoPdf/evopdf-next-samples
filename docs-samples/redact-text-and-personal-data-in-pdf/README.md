# Redact Text and Personal Data in PDF

The T:EvoPdf.Next.PdfRedactor class permanently removes the text, images and graphics of some areas of an existing PDF document. The texts to remove can be searched in all the pages, the personal data like email addresses, phone numbers, bank accounts and payment card numbers is found by its structure and the redacted areas are covered with a fill color and an overlay text. The removed content cannot be recovered from the saved document, unlike the content hidden under a shape drawn over the page.

Source topic: https://www.evopdf.com/help/evopdf-next-dotnet/html/redact-text-and-personal-data-in-pdf.htm
